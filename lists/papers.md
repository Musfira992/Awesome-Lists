# Interesting papers

Titles and a one-line why, with arXiv, DOI, or PDF links. No full text reproduced here.

1. [MIMIC-Extract: A Data Extraction, Preprocessing, and Representation Pipeline for MIMIC-III](https://arxiv.org/pdf/1907.08322) - Reproducible pipeline for turning MIMIC-III into analysis-ready tables; great for clinical ML starters.
2. [Moderated estimation of fold change and dispersion for RNA-seq data with DESeq2](https://doi.org/10.1186/s13059-014-0550-8) - Core differential expression method still used daily in RNA-seq workflows.
3. [Salmon provides fast and bias-aware quantification of transcript expression](https://doi.org/10.1038/nmeth.4197) - Quasi-mapping transcript quantification that reshaped RNA-seq practice.
4. [HISAT: a fast spliced aligner with low memory requirements](https://doi.org/10.1038/nmeth.3317) - Fast splice-aware alignment foundational to many RNA-seq pipelines.
5. [edgeR: a Bioconductor package for differential expression analysis of digital gene expression data](https://doi.org/10.1093/bioinformatics/btp616) - Early and still widely used Bioconductor approach to count-based DE.
6. [The Sequence Alignment/Map format and SAMtools](https://doi.org/10.1093/bioinformatics/btp352) - Defined SAM/BAM and the tooling that still underpins NGS analysis.
7. [Minimap2: pairwise alignment for nucleotide sequences](https://doi.org/10.1093/bioinformatics/bty191) - Fast aligner for long and short reads; default choice for many long-read workflows.
8. [MultiQC: summarize analysis results for multiple tools and samples in a single report](https://doi.org/10.1093/bioinformatics/btw354) - Quality-control aggregation that makes multi-sample pipelines reviewable.
9. [Orchestrating single-cell analysis with Bioconductor](https://doi.org/10.1038/s41592-019-0654-9) - Framework paper for consistent single-cell analysis in R/Bioconductor.
10. [Near-optimal probabilistic RNA-seq quantification](https://doi.org/10.1038/nbt.3519) - kallisto; lightweight pseudoalignment that popularised ultra-fast quantification.
11. [The Gene Expression Omnibus (GEO): A gene expression resource](https://doi.org/10.1093/nar/gkaa1010) - Overview of GEO as a primary public functional genomics archive.
12. [Thirty years of plant transformation technology development](https://doi.org/10.1111/pbi.13504) - Plant biotech methods review useful for ag and molecular genetics context.
